# Gun pictures

Put one picture per gun in this folder, named exactly as below. Any gun without a picture just shows without one.

- PNG with a transparent background looks best (a side view of the gun).
- About 800 px wide is plenty.
- To use a different file name or a .jpg/.webp, set `image` on that build in `js/builds.js`.
