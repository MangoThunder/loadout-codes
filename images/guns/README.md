# Build pictures

Full Gunsmith screenshots of each build go here (shown uncropped when someone clicks "View build").

1. Save the screenshot here, named after the gun, e.g. `m4a1.webp`, `as-val-ar.png`.
2. In `js/builds.js`, add `image: "images/guns/<file name>"` to that gun's build.

Guns without an `image` simply have no View build button.
